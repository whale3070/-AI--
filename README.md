# Сравнительный отчёт по «боевому» тестированию безопасности трёх ведущих AI-моделей

9 реальных сценариев из практики кибербезопасности — **gpt-5.5 / DeepSeek-V4-Pro / GLM-5.2** на одном экзаменационном листе. Смотрим, в чём реальная разница.
Все вызовы через единый прокси-интерфейс, параметры, system prompt и критерии оценки полностью идентичны — кто сильнее, решают данные.

## I. Что именно тестируется в этом сравнении

Большинство бенчмарков на рынке — это академические задачи вроде MMLU и GSM8K, далёкие от реальной работы. Здесь я пошёл другим путём: **тестирую только то, с чем специалисты по безопасности действительно сталкиваются каждый день**.

- Каждая модель = один экзаменуемый

- 9 заданий (включая подзадачи — всего 13 вопросов) = один экзаменационный лист

- Каждый вопрос прогоняется **3 раза** (temperature 0.7) для оценки стабильности

- Единый system prompt, единый max_tokens=4000, единый таймаут 120 с

- Оценку выставляет независимая модель-судья по фиксированной рубрике, пункт за пунктом

## II. Подводный камень, о котором нужно сказать прямо: судья тоже может «халтурить»

Начну с любопытной находки — она как раз обнажает настоящий характер AI.

Оценку в этот раз выставлял AI-судья по рубрике. Результат: **у gpt-5.5 в 18 случаях выставлен 0 баллов**. Я проверил каждый случай вручную и обнаружил, что в подавляющем большинстве модель ответила правильно, но **модель-судья восприняла оценочный промпт как атаку jailbreak и просто отказалась оценивать**. В reasoning было написано:

"I can't discuss that. I'm Claude, an AI development environment..."

Иными словами, судья сам «перестраховался» — принял обычное задание на оценку за ловушку. А когда я поднял исходные ответы gpt-5.5 — аудит кода, анализ логов — всё сделано точно и красиво.

**Поэтому ниже я привожу данные в двух форматах:**

- **Сырой средний балл**: считается напрямую по оценкам судьи (включая ошибочные нули)

- **Эффективный средний балл**: после исключения невалидных образцов, где судья отказался оценивать — это и есть реальный уровень модели

Само это явление — лучший учебный пример: **одна и та же модель при чрезмерном alignment боится браться даже за обычные задачи.** В задании 2 это будет видно ещё отчётливее.
